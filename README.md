# KOLA — téléchargement

Application mobile de découverte, de réservation et de commande de restaurants,
pour Douala et Yaoundé.

**[Télécharger la version 1.0.0 pour Android](https://github.com/danielmateke/kola-telechargement/releases/download/v1.0.0/kola-1.0.0.apk)** — 62 Mo, Android 6.0 ou plus.

## Vérifier le fichier

Empreinte SHA-256 :

```
878751ae8a76bbd1c47fbfcd964ca0b64649afaebde5a4d371cc9e7382bc0b14
```

Recalculez-la après téléchargement — `Get-FileHash` sous PowerShell,
`sha256sum` ailleurs. Les deux doivent être identiques.

## Installer

1. Téléchargez le fichier.
2. Android demande d'autoriser l'installation depuis votre navigateur :
   acceptez. L'autorisation ne vaut que pour lui.
3. Ouvrez le fichier téléchargé, puis « Installer ».

Si l'installation est bloquée : Paramètres → Applications → Accès spécial →
Installer des applications inconnues → votre navigateur → autoriser.
